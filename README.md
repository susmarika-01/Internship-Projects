# 🎓 Attendance Tracking System  

This project is a **💼 Modern Attendance Management System** built using **🐍 Python** and **🌐 Streamlit**, designed to simplify how organizations **record, manage, and analyze employee attendance**. With an elegant and responsive interface, it transforms routine attendance tracking into a **visually engaging and data-driven experience**.  

The system features two main modules - **📝 Mark Today’s Attendance** and **📊 View Past Attendance**. In the first section, HR staff or team leads can effortlessly **mark employees as “Present” or “Absent”**, with each record automatically saved in a date-based CSV file for easy tracking. The second section offers a **comprehensive analysis of attendance history**, showcasing **daily summaries, attendance rates, and employee-specific details** - all presented in a clean, dashboard-style layout.  

Users can also **filter results**, **sort employee data**, and even **📥 download attendance reports** for documentation or further insights. The sidebar provides **real-time quick stats** such as total employees, available records, and system status indicators - all wrapped in a polished UI powered by **custom CSS gradients, interactive hover effects, and smooth transitions**.  

Overall, this project beautifully blends **data management (`pandas`)**, **file handling (`os`, `glob`)**, and **interactive web design (`Streamlit`)** to create a **lightweight yet powerful tool** for organizations seeking to **streamline attendance tracking and enhance productivity** - all in one intuitive platform. 🚀
